# Circular Membrane Problem 

- **visualization.py** -  My coursework is here. In this file I solved Helmholtz equation in polar coordinates, it is also a boundary value problem. (Note: It is not directly used in the main program)
- **RoundMembrane.py** -  Separate file where I embed matplot plots into PySide6 (Qt6) window. This made it possible to modify the 'n' and 'm' modes and view the visualization in real-time.
- **main.py** - It`s a PySide6 (Qt6) application with simple menus.
